/ Editorial standard

Treat the chart as a news document

Every visible layer must encode data, supply context, establish hierarchy, support verification, or direct attention to the narrator’s current claim. If removing a layer does not reduce comprehension, remove it.

Evidence first

Prefer a quiet field, explicit scale, sparse dates, neutral history, one semantic accent, direct annotation, and visible sourcing.

Motion with a purpose

Visual interest comes from sequencing, comparison, annotation, and the arrival of evidence—not ornamental motion.

/ Preflight

Verify before design

Locate the project

Find the Remotion root, composition entry point, package manifest, project instructions, and any project-specific Remotion skill.

Confirm the environment

Check compatible Remotion, React, and TypeScript dependencies and identify Studio, type-check, still-render, and video-render commands.

Define the targets

Record composition IDs, frame rate, duration, dimensions, required aspect ratios, design tokens, and reusable chart components.

Run the cheapest check

Normally type-check or list compositions. Record missing dependencies or render prerequisites instead of designing around them.

/ Information architecture

Build the frame in editorial order

State the measure

Use a precise title, readable unit, and a visible source immediately below the header. Do not insert unsupported causality.

Make magnitude legible

Use an honest baseline, enough scale to interpret the data, and sparse axes or dates that supply context without becoming wallpaper.

Annotate only the finding

Directly annotate the one or two findings used by the narration. Do not duplicate dates, values, labels, or legends.

/ Visual system

One semantic accent, not decoration

Use

  • A flat warm paper, off-white, or dark editorial field.
  • Neutral colours for history or comparison.
  • One accent for the subject, anomaly, current period, or conclusion.
  • Readable axes, direct labels, restrained grid lines, and visible sourcing.

Remove

  • Terrain, contours, particles, ambient parallax, glow, or vignette that encodes nothing.
  • Fake paper texture, ornamental frames, glassmorphism, dashboard chrome, and gratuitous cards.
  • Gradients without quantitative meaning, tiny footer sources, and accent colour on every mark.

/ Motion grammar

Let the evidence be the event

Establish

Bring in the title, source, unit, grid, and axes before the data asks for attention.

Build the baseline

Reveal historical or comparison data in chronological or argumentative order, then pause so it can be read.

Introduce the subject

Make the anomaly, current period, or second series a distinct event. Add the conclusion only after its evidence is visible.

Hold

Keep the completed chart stable for roughly 0.5–1 second or longer while narration continues.

/ Editorial timeline

Make the important timings adjustable

Use one central, typed timing contract. Name roles for editorial function, expose meaningful events in Remotion Studio, and derive interpolation windows from that source of truth.

/ Verification

Inspect rendered pixels

Before implementation

Before handoff

Run project checks, list registered compositions, render early, middle, climax, and final-hold frames, and inspect every required aspect ratio at actual output size.
