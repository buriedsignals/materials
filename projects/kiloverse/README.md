# Into the Kiloverse

Public production and transparency materials for the Buried Signals video on
Kilo grupė and the network around it, made with Indicator and partner newsrooms.

- `project.json` describes the public sources, methodology, AI disclosure, the
  related skill and the Kiloverse map.
- `media/` holds partner logos shown in the page header.

Canonical page: <https://materials.buriedsignals.com/kiloverse/>

Evidence for every claim lives in the case folder
(`investigations/health-insider/`), which is not published: registry extracts
there contain personal data.
