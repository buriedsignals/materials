# Water Wars

Public production and transparency materials for the Water Wars video.

- `project.json` describes the public sources, corrections, methodology, AI
  disclosure, related skills, and lab experiments.
- `data/fact-check.json` contains verdicts and claim-to-evidence grounding.
- `data/evidence.json` is the public source and capture-hash ledger.
- `geo/` contains project-specific geographic data.
- `media/` contains rendered examples used by the skill documentation.

Canonical page: <https://materials.buriedsignals.com/water-wars/>
